一、什么是面向对象

面向对象编程的核心，是把数据和处理数据的行为组织在对象中，再让不同对象相互协作。

例如要处理一条公告，如果不使用对象，可能会写成：

使用对象后，可以用一个 Notice 对象表示一条完整的公告：

调用方不需要直接修改“是否发布”字段，只需要调用 notice.publish()，告诉公告对象执行“发布”行为。如何完成发布，由 Notice 类内部的代码负责。

因此，面向对象不是把所有代码都拆成很多类，而是尽量让数据和规则有清晰的归属。

1. 构造方法负责初始化对象

Java 通过参数列表区分重载方法。参数列表不同包括：

  • 参数数量不同：publish() 和 publish(boolean)
  • 参数类型不同：find(Long) 和 find(String)
  • 参数顺序不同：send(String, Long) 和 send(Long, String)

重载方法名相同，但参数列表必须不同。不能只通过修改返回类型实现重载。

六、继承：表达“是一种”关系

当两个类存在明确的“是一种”关系时，可以考虑继承。

例如，普通公告和重要公告都是公告：

  • extends Notice 表示 UrgentNotice 继承 Notice
  • Notice 是父类，UrgentNotice 是子类
  • 子类继承父类可访问的字段和方法
  • super(id, title) 调用父类构造方法，必须放在子类构造方法第一行

4. 重载和重写的区别

对比项 重载 Overload 重写 Override
发生位置 通常在同一个类中 父类和子类之间，或接口和实现类之间
方法名 相同 相同
参数列表 必须不同 必须匹配
选择时机 编译时根据参数选择 运行时根据实际对象选择
主要作用 为相同操作提供不同参数形式 让子类提供自己的行为
